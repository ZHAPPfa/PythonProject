# PythonProject

#生物医学文献RAG问答助手

##背景
博士期间需要快速检索肺损伤修复方向的文献，关键词搜索命中率低。本项目用RAG方法搭建了一个基于个人文献库的问答助手。

##做了什么
-收集了数十篇肺损伤修复/干细胞再生方向的文献摘要（英文）
-用BGE中文向量模型（bge-small-zh-v1.5)做向量化，存入ChromaDB
-用LangChain搭建检索增强生成链路，LLM使用DeepSeek API
-测试了四个问题（三个中文+一个英文），验证检索和生成能正常工作

##测试结果
-匹配文献库主要问题（如”肺泡干细胞如何参与肺损伤后的修复？”）能返回有依据的答案，并附来源。
-超出文献库范围的问题（如“迷走神经如何调控肺部干细胞的修复？”）会诚实回答“文献中未找到”。
-当前局限：检索结果集中在少数高度匹配的文献上，文献库多样性不足。

##已知局限与下一步
-文献库以肺损伤修复为主，神经调控方向文献较少
-下一步计划：补充10-15篇神经调控方向文献；对比不同chunk_size对检索多样性的影响。

##如何运行
1.安装依赖：‘pip install -r requirements.txt'
2.设置环境变量：'DEEPSEEK_API_KEY=你的key'
3.建索引：python build_index.py
4.检索问答：python query.py
